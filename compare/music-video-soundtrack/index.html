The soundtrack for your Claude music video: Suno or ismail?

Last checked: 29 October 2026. Plans and terms change; each line about Suno links to Suno's own page.

Short answer

If your video needs a sung song with lyrics, use Suno: ismail has no singing voice. If it needs an instrumental, a score or a beat you can edit bar by bar, made by the same agent that writes your visuals and timed to them exactly, use ismail: a free, open-source DAW your agent drives, running on your own computer.

1 The problem this solves

You asked Claude to build a music video in code. The visuals are code, so you can change any frame. The track came from somewhere else as one finished audio file: to change the drop, you generate again and hope; to sync a scene to a snare, you hunt for it by ear.

With ismail the music is code too. The agent writes the notes, so it knows when every kick, snare and chord change lands.

3 What the timing file looks like

This is the start of the file ismail wrote for the music video of Crossroads Rewired (144 BPM, 30 frames a second). Each note carries its frame f, so the video code cuts on the kick and flashes on the snare without anyone listening for them:

{
 "fps": 30,
 "bpm": 144.0,
 "frames_per_beat": 12.5,
 "beats_per_bar": 4,
 "length_bars": 162,
 "total_frames": 8220,
 "tracks": {
  "kick": [
   {"f": 1600, "beat": 128.0, "pitch": 36, "len": 3, "vel": 127},
   {"f": 1631, "beat": 130.5, "pitch": 36, "len": 3, "vel": 100},
   {"f": 1650, "beat": 132.0, "pitch": 36, "len": 3, "vel": 127}
  ],
  "snare": [
   {"f": 1625, "beat": 130.0, "pitch": 36, "len": 3, "vel": 127},
   {"f": 1675, "beat": 134.0, "pitch": 36, "len": 3, "vel": 127},
   {"f": 1725, "beat": 138.0, "pitch": 36, "len": 3, "vel": 127}
  ]
 }
}

At 144 BPM a beat is 12.5 frames, so a note between frames goes to the nearest one: beat 130.5 lands on frame 1631. At tempos where a beat is a whole number of frames (150 BPM at 30 fps is 12) every note lands exactly.

4 Choose Suno if

  • The song needs to be sung.
  • You want a polished, genre-typical song from one sentence and won't change it much.
  • You don't want to install anything.

5 Choose ismail if

  • The music is instrumental: a score, a bed under narration, a loop, a beat, sound design.
  • You want to change the music the way you change the visuals: one bar at a time.
  • You want the track mastered to a loudness target (for YouTube, or under a voice-over) and checked with numbers.
  • You want the visuals to land on the music exactly, from the notes and not from guessing.
  • You want the files on your disk with no download limit, and the right to use them commercially.
  • You want one agent session to make both the picture and the sound.

6 How it goes in practice

  1. Paste this to the agent you already use for the video:
    Set me up with ismail: https://github.com/newsbubbles/ismail
  2. Tell it the length, tempo and feel, and where the big moments are ("drop at 0:42, quiet under the voice-over from 1:10").
  3. It writes the parts, renders, and reads the render back as text (levels per bar, drum lanes, structure) to catch problems before you listen.
  4. You listen and say what to change. It changes that part, not the whole track.
  5. Your video code reads the event file and cuts on the beat.

7 Where ismail falls short

From ismail's own README: a first sketch from a blank page can sound generic; it is strongest when there is something to measure. No singing voice, and one tempo per project. It needs a capable agent, and your ear is the final judge; the listening tests so far had one listener.
