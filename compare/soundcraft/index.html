ismail vs SoundCraft: which one should your agent use?

Last checked: 22 October 2026. SoundCraft is pre-alpha and changes daily; every line about it links to where we read it.

Short answer

If you record and edit audio the Pro Tools way, want your plugins and MIDI, and want an agent to drive the same app you use, use SoundCraft. If you want the agent to make the music itself and check every render as text before you listen, use ismail. They do different jobs and can work together through audio and MIDI files.

1 What each one is

  • SoundCraft is an open-source, clean-room re-implementation of Avid Pro Tools in Rust, for macOS, Windows, Linux, FreeBSD and the browser (README). Every menu action is a command with JSON parameters, and an MCP server lets an agent list commands, run them (up to 1,000 in a batch), inspect the session, bounce the mix and take screenshots of the app (MCP docs). Its README calls it pre-alpha.
  • ismail is a DAW written for an agent. The agent writes notes, instruments, effects and the mix as text, ismail renders the audio, and the agent gets every render back as text: levels per bar, drum lanes, piano rolls, chords, song structure and scored comparisons against a reference. The agent also builds the screens you steer it through: a phone page, feedback pages, a VR stage.

3 What "the render comes back as text" looks like

This is part of what ismail's agent reads from a finished track, Uke Story. One character per bar (9 = loudest, each step down = 4 dB):

      bar 123456789012345678901234567890123456789012345678901234567890...
      mix 66666687787787787887888888888888888888888888888878889999888888...
     ~sub 777777777777777777777776777777666666777777777777.7899999999999...
  section A----------------------------------------------|B------|C------...

A   bars   1-48  (48)  level 9.6 dB   low X...X...X...X...  snare ....x.......x...
B   bars  49-56  ( 8)  level 12.6 dB  low XxxXX.XxXxxXxxXx
C   bars  57-78  (22)  level 12.7 dB  low XxXXXxXxXXXX.XXx  snare x.xXx..xX.x.x..x

The agent can see where the sub drops out, which bars repeat and where the kick pattern changes. In SoundCraft, an agent can get the loudness and peak of a bounce, beat times from audio and chord names from MIDI notes. ismail's readings cover the whole mix: levels per band and bar, sections, drum patterns, and comparisons against a reference.

4 Choose SoundCraft if

  • You record, comp and edit audio and want a Pro Tools workflow without Pro Tools.
  • You rely on your plugins or surround.
  • You want to stay at the controls and let an agent handle the tedious edits in the same app.

5 Choose ismail if

  • You want the agent to do the whole job: write, render, check the result, fix, render again, and ask you what you hear.
  • You want to steer by listening and talking, from your phone or a VR stage, not by clicking through menus.
  • You want to build an instrument from recorded notes (a few for most instruments, more for one whose colour changes note to note, like the piano), or match the feel of a reference record.
  • You want the agent to do the sound engineering too: mix, master to a loudness target, and check both with numbers.
  • You want to jam: play or sing a part into your phone and hear it come back as a loop.
  • You want the agent to play a set live.

6 Can I use both?

Yes, through stems and MIDI files. ismail renders each track as its own WAV stem and exports the notes as a .mid, and a DAW imports both. ismail can measure and plan; SoundCraft can host your plugins and edit recordings.

7 Where ismail falls short

ismail says this on its own README: a new song from a blank page can sound generic on the first sketch, and it is strongest with something to measure. It has no singing voice and one tempo per project. In a live set, the agent's own changes land between its turns, 5 to 30 seconds apart, and the VR stage is tested on one headset with one person. It needs a capable agent, and your ear stays the final judge; the listening tests so far had one listener.
